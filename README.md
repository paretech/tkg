# tkg
Python Tkinter GUI Related


## Feature Requests
- Configuration Manager
- Scheduler
- Event Handler
- Log Viewer
  - Built on logging.handlers.QueueListener, logging.handlers.QueueHandler
  - Get counts of each log level
- Status Bar
  - Generic bar. Easily add counts for how many messages logged for each log level, unhandled exception count, thread count, and more.
- Hex Viewer
- Tile based image viewer
  - Efficiently show and interact with very large images (e.g. zoomed in deep on a "normal" resolution image)
